Your API key is stored in your browser's encrypted sync storage and is sent only to the provider you choose. Smartii has no server.

5 · Updates

Smartii checks GitHub for a newer version every 30 minutes (and whenever you click below). Load-unpacked installs can't self-install, so you'll get a one-click link to download the latest release.

Download latest →

Update in place (no zip) — for git clone installs

Chrome won't let an extension overwrite its own files, so true silent self-update isn't possible for unpacked installs. But if you installed with git clone, you can update without downloading a zip:

  1. Pull the latest code into the Smartii folder:
    bash installer/update-smartii.sh (or git pull)
  2. Click Apply & reload below — the new code loads instantly.

For true zero-touch updates, install from the Chrome Web Store instead.

6 · Use it

  • Ctrl + Shift + S (⌘+Shift+S on Mac) — toggle Smartii on the active tab
  • Alt + Shift + S (⌥+Shift+S on Mac) — screenshot the screen + solve immediately
  • Alt + Shift + G (⌥+Shift+G on Mac) — Godmode: auto-solve & auto-fill everything on screen (Pro)
  • Esc — close the bar
  • Click the 📸 Solve button or press Ctrl+Enter (or ⌘+Enter on Mac) in the input to capture + solve

Change the shortcut at chrome://extensions/shortcuts.
