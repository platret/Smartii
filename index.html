AI at the bottom of your browser. Press a key. Get the answer.

Smartii is a tiny extension that summons an assistant bar on any page. Type a question, or screenshot what's on screen and let the model solve it. Works with free providers (Gemini, Groq, OpenRouter) and paid ones (Claude, ChatGPT).

Why Smartii

⌨️

Keybind, not a tab

One shortcut on any page. The bar appears at the bottom — read the page in the background while it works.

📸

Sees what you see

Press Solve, Smartii screenshots the visible page and sends it to the model. Homework, errors, UIs — anything visual.

🔑

Your key, your data

BYO API key. Keys live in your browser's encrypted sync storage. No backend by default. Free providers supported.

🎛️

7 providers in one

Gemini, Groq, OpenRouter, Hugging Face, Claude, ChatGPT, Perplexity. Switch with a click.

🎨

Fits your vibe

Solid or glass theme. Accent color, width, radius — all tunable.

⚡

Godmode (Pro)

One press → Smartii reads the screen and answers everything, no typing needed. Quizzes, exams, code errors, anything.

⚡ Pro Feature

Godmode does it all for you.

Hit Ctrl+Shift+G. Smartii screenshots the page, identifies every question, problem, error, or task on screen, and answers them all — directly, completely, without you typing a word.

  • ✅ Multiple-choice: gives the correct letter and reasoning
  • ✅ Code or error: gives the fix
  • ✅ Forms / quizzes: numbered answers in order
  • ✅ Visual puzzles: reads the image too

Install in 60 seconds

  1. Download the latest release from GitHub Releases.
  2. Unzip the archive (or run the macOS / Windows installer).
  3. Open chrome://extensions, turn on Developer mode.
  4. Click Load unpacked → pick the Smartii folder.
  5. Pick a provider, paste your API key — done.
