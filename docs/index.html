Why Smartii

An assistant that lives where you work.

No new tab. No copy-paste. Just a keystroke on whatever page you're already on.

Keybind, not a tab

One shortcut on any page. The bar appears at the bottom — keep reading while it works.

Sees what you see

Hit Solve — Smartii screenshots the visible page and sends it to the model. Homework, errors, UIs, anything visual.

Your key, your data

Bring your own API key. Keys live in your browser's encrypted sync storage. No backend by default.

7 providers in one

Gemini, Groq, OpenRouter, Hugging Face, Claude, ChatGPT, Perplexity. Switch with a click.

Fits your vibe

Solid or glass theme. Accent color, width, radius — all tunable from a one-screen settings page.

Godmode Pro

One press → Smartii reads the screen and answers everything, no typing. Quizzes, exams, code errors, anything.

⚡ Pro feature

Godmode does it all for you.

Hit AltShiftG. Smartii screenshots the page, finds every question, problem, error or task on screen, and answers them all — directly, completely, without you typing a word.

  • Multiple-choice: the correct letter and the reasoning
  • Code or error: the actual fix, ready to paste
  • Forms & quizzes: every answer, numbered in order
  • Visual puzzles: it reads the image too

Setup

Install in 60 seconds.

  1. 1
    Download the latest release from GitHub Releases.
  2. 2
    Unzip the archive (or run the macOS / Windows installer).
  3. 3
    Open chrome://extensions and turn on Developer mode.
  4. 4
    Click Load unpacked → pick the Smartii folder.
  5. 5
    Pick a provider, paste your API key — done.
